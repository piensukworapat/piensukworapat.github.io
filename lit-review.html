Literature Review

Derivation of the action

  • N. Ishibashi, H. Kawai, Y. Kitazawa, A. Tsuchiya, "Large-N reduced models as superstring", Nucl.Phys.B 498 (1997) 467-491

    • The original paper that proposed the IKKT matrix model as a non-perturbative definition of the type IIB superstring theory. It showed that the action of the IKKT matrix model can be derived formally from (1) 10D N=1 super Yang-Mills theory via large-N reduction and (2) type IIB Nambu-Goto action in the Schild gauge via matrix regularization.

  • E. Witten, "Bound States Of Strings and p-Branes", Nucl.Phys.B 460 (1996) 335-350

    • First, the (p+1)D worldvolume theory of N Dp-branes is equivalent to the 10D SU(N) super Yang-Mills theory reduced to p+1 dimensions, which gives Dp-branes picture to the reduced model. Then, he considered p=-1 and p=0 case, where he derived the same action as those of the IKKT matrix model and the BFSS matrix model. ***It is important not to mistaken this paper as the first proposal of the IKKT matrix model because this paper only wrote down the action and some connection to type IIB superstring via D0-branes picture, while the original IKKT matrix model paper was the first to provide in-depth investigation into the more direct derivation of the action using matrix regularization, the symmetries, reproducing the interactions between D-objects, and the trace part of the matrices as collective spacetime coordinates.
